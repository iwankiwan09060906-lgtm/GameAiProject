# DECISIONS

문서에 없어서 스스로 정한 것을 한 줄씩 적는다.

- 2026-10-26 풀숲·나무(`props/foliage_*`)를 맵 문자 `f`로 추가: 이동만 막고 시야·총알·빛·소리는 투과(ASSET_DIRECTION "장식, 이동만 막음"을 가장 단순하게 해석). 요구사항 #32.
- 2026-10-26 크레딧 문구는 `StreamingAssets/Config/credits.txt` 한 파일에서 읽어 그대로 표시(ASSET_CREDITS 5장과 같게 유지, 없으면 "외부 에셋 없음" 기본 문구). 요구사항 #31.
- 2026-10-26 야외 환경음은 플레이어 칸 바닥이 `o`일 때 0.5초 페이드 인/아웃, 배경음 음량을 따름. 파일 위치는 `Audio/bgm/`.
- 2026-10-26 조명 연출 값(전역광 색, 천장등 색·Falloff, 그림자 강도, 총구 빛, 야간 투시, 필름 그레인)은 `game.json`의 `lighting`에 둠.
- 2026-10-26 변형 스프라이트(`_*`)는 맵 소품이면 칸 좌표 해시로, 혈흔·총구 화염이면 연출 난수원으로 고름. 캐릭터 시트는 가로 32×32 프레임, 걷기 8fps·사격 0.1초.
- 2026-10-26 외부 에셋 연결은 `AssetCatalog`(ScriptableObject) + 에디터 `AssetCatalogBuilder`로 정함. 이유: 빌드된 게임은 `Assets/` 경로를 못 읽고, `Resources`는 폴더 규칙을 강제하며, StreamingAssets 런타임 로딩(PNG/OGG 디코딩)은 코드가 많음. 카탈로그는 씬이 직접 참조하므로 빌드에 자동 포함되고, 파일이 없으면 코드 생성 폴백. 교체 절차: 파일을 넣고 `Tools/Build Project`.
- 2026-10-26 Dark Ambience Loop(추격·교전 배경음 예비)는 아직 ID를 주지 않음. 쓰기로 하면 `bgm_combat`을 추가하고 CC BY 3.0 크레딧을 넣는다.
- 2026-11-03 외부 에셋을 `Assets/_Project/`에 정리. 사용한 원본·라이선스와 재생성 스크립트는 `AssetSource/`에 두고(Unity 임포트 대상 밖), 쓰지 않는 원본 약 500MB는 삭제. 잘라내기·재채색은 Python·ffmpeg가 없어 PowerShell + .NET으로 처리.
- 2026-11-03 dyru 캐릭터에 총이 없어 `chars/held_*`를 겹쳐 그림(무기 교체가 쉬움). 시트 열은 페이지 설명 순서대로 걷기·총 들기·사격·근접으로 해석하고, 항상 총을 들고 있으므로 idle=총 들기, walk=총 들기+사격 2프레임, shoot=사격으로 씀. 근접 프레임은 `player_melee`로 추가.
- 2026-11-03 캐릭터 배정: 플레이어=회색(밝게), 경비병=주황 헬멧(어두운 붉은 갈색으로), 소총병=녹색 체크(채도·명도 낮춤). 문서에는 "4색 중 회색"이라 했지만 4색 시트에 회색이 없어 기본 시트(`shooter_up.png`)를 씀.
- 2026-11-03 `tile_wall.png`는 거의 검정 타일이고 1px 선을 넣지 않음. 타일에 넣으면 칸마다 격자가 보이므로, 바닥과 맞닿은 변에만 맵 렌더러가 선을 그림.
- 2026-11-03 Firearm Library에는 사격음만 있어 재장전은 RPG Audio `metalClick`, 빈 탄창은 Interface `click_002`로 대체. 소음권총은 원본 그대로 쓰고 코드에서 피치를 낮추지 않음.
- 2026-11-03 사격음 2개는 96kHz 24bit 녹음의 첫 발을 0.12초만 잘라 48kHz 16bit 모노 `.wav`로 저장(ogg 인코더가 없음). `amb_outdoor_night`는 받은 그대로 `.mp3`라서 확장자 규칙에 `.mp3` 추가.
- 2026-11-03 효과음 길이는 11.2 기준과 다른 것이 있음(문 0.92초, 경고음 0.5초 등). 파일 ID 맞춤을 우선하고 실제 길이는 ASSET_DIRECTION 3.2에 기록.
- 2026-11-03 Trees & Bushes는 시트가 불투명이라 바깥 잔디를 지워 작은 나무 2종만 씀. 큰 나무는 110px 안팎이라 64×64 규격에 안 맞아 제외. `foliage_*`는 전부 32×32.
- 2026-11-03 총구 화염은 16×16으로는 작아 4장을 24×20으로 통일, 이름은 변형 규칙대로 `muzzle_flash_1~4`. 왼쪽 끝이 총구.
- 2026-11-03 Bloodsplatter(고해상도)와 Neo둥근모(`.ttf` 없음)는 제외. 피격 피는 Reactorcore 9프레임을 `hit_blood_*`로 추가, 폰트 대체 순서에서 NeoDunggeunmo 삭제.
- 2026-11-03 외부 에셋이 없던 초상화·폭탄·탈출·유인탄·아이콘·자세 실루엣·패널·천장등·탄피를 코드로 그려 임시본으로 넣음(`AssetSource/drawn/`). 문서의 직접 제작 항목이지만 개발 전에 모두 갖추라는 요청에 따름. 픽셀을 지정한 코드 생성 에셋으로 보고 이미지 생성 AI는 쓰지 않음. 수업 규정이 이것도 생성 도구로 본다면 교체.
- 2026-11-03 초상화는 목표 화면 캐릭터를 베끼지 않고 새로 디자인. 조력자=갈색 단발·붉은 스카프, 플레이어=회색 복면.
- 2026-11-03 패널은 파일 이름이 없어 `panel_dark`·`panel_gold`·`panel_dialogue`로 정함. 16×16 9-slice.
- 2026-11-03 테스트가 게임 코드를 참조해야 해서 asmdef 3개(`GameAi.Runtime`, `GameAi.Editor`, `GameAi.Tests.EditMode`)를 둠. 네임스페이스는 `GameAi` 하나.
- 2026-11-03 프리팹을 만들지 않고 플레이어·적·문을 런타임 코드로 조립. 외부 에셋과 코드 생성 폴백을 같은 경로로 처리하기 쉽고 씬·프리팹 수작업이 없기 때문. `Prefabs/`는 비어 있음.
- 2026-11-03 시스템 Tick은 `GameManager`가 순서대로 부르고, 이벤트 구독이 필요 없는 시스템은 MonoBehaviour가 아닌 일반 클래스로 둠.
- 2026-11-03 JsonUtility가 중첩 배열을 읽지 못해 맵의 `patrol: [[x,y]]`를 읽기 전에 `[{"v":[x,y]}]`로 바꿈(`MapJson.Normalize`). 파일 형식은 문서 그대로.
- 2026-11-03 문서에 JSON 위치가 없던 수치를 추가: `game.json`의 `player`·`view`·`fog`·`fx`·`crosshair`, `lighting.wall_rim_color`, `weapons.json`의 `melee`. 값은 7장 그대로.
- 2026-11-03 전역광 세기를 문서 값(0.15)으로 그대로 쓰면 `#1A1830`과 곱해져 화면이 완전히 검어져서, 화면용은 `global_intensity_scale`(10)을 곱함. 판정용 밝기는 문서 값 유지. 전역광이 하나뿐이라 야외가 더 어두운 것은 바닥·풀숲 타일 색으로 표현.
- 2026-11-03 필름 그레인 알파 0.04를 그대로 쓰면 Linear 색공간에서 화면이 뿌옇게 떠서, 화면 밝기 기준이 되도록 GammaToLinear로 바꿔 적용.
- 2026-11-03 벽 1px 윤곽은 벽 그림자 안에서도 보이도록 조명을 받지 않게 함. 조준선은 `ref_01` 크기에 맞춰 배율 1. 기억 덮개 색은 벽이 바닥보다 밝게 뜨지 않도록 `memory_gray` 0.04.
- 2026-11-03 Galmuri11은 도트 격자가 12px이라 문서의 "11의 배수" 대신 12의 배수(샘플링 24)를 씀. 렌더 모드는 힌팅 없는 Raster.
- 2026-11-03 시야는 부채꼴 레이 90개로 구하고, 스치듯 지나 비는 벽면이 없도록 보이는 칸에 맞닿은 막힌 칸도 보이게 함. 안개는 1칸=1픽셀 Point 필터라 경계가 칸 단위로 보임.
- 2026-11-03 문은 양옆이 벽이면 가로 막대, 아니면 세로 막대. 열린 문 칸에 살아 있는 대상이 있으면 닫지 못함(시체는 막지 않음). 상호작용은 1.2m 안이어도 벽 너머 대상은 고르지 않음.
- 2026-11-03 이동 충돌은 Physics2D 없이 원-칸 밀어내기로 처리. 면에 닿은 칸을 먼저 밀어 벽 이음새에 걸리지 않게 함. 플레이어와 살아 있는 적은 겹치지 않고 시체는 지나감.
- 2026-11-03 탄창이 비어도 자동 재장전하지 않음(문서에 없음). 근접 제압은 벽 너머로 되지 않음.
- 2026-11-03 Phase 3까지 메인 메뉴가 없어 `MainMenu` 씬은 바로 게임 씬으로 넘어감. 소리는 Phase 7, 소음 이벤트는 Phase 4라서 지금은 사격음·발소리가 나지 않음.
- 2026-11-03 빌드를 `-smoke <폴더>`로 실행하면 `SmokeRunner`가 정해진 조작을 재생해 판정과 스크린샷을 남김. 입력을 `IInputSource`로 분리해 13.3 입력 재생에도 쓸 수 있음.
- 2026-11-03 TMP 기본 리소스(`Assets/TextMesh Pro`)는 임포트가 비동기라 저장소에 포함. 없으면 `Tools/Build Project`가 임포트 뒤 이어서 실행.
- 2026-11-03 Phase 0~3을 한 번에 구현해 Phase별 커밋은 영역별로 나눔. 중간 커밋은 단독으로 컴파일되지 않을 수 있고, 검증은 마지막 커밋(phase-3) 기준.
- 2026-11-03 niro58 Weapon Pack은 페이지에서 CC0 확인. OpenGameArt 페이지는 자동 접속이 막혀 재확인 못 한 12개를 `사용(재확인 필요)`로 표시.
