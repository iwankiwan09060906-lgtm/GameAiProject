- 2026-10-26 야외 환경음은 플레이어 칸 바닥이 `o`일 때 0.5초 페이드 인/아웃, 배경음 음량을 따름. 파일 위치는 `Audio/bgm/`.
- 2026-10-26 조명 연출 값(전역광 색, 천장등 색·Falloff, 그림자 강도, 총구 빛, 야간 투시, 필름 그레인)은 `game.json`의 `lighting`에 둠.
- 2026-10-26 변형 스프라이트(`_*`)는 맵 소품이면 칸 좌표 해시로, 혈흔·총구 화염이면 연출 난수원으로 고름. 캐릭터 시트는 가로 32×32 프레임, 걷기 8fps·사격 0.1초.
- 2026-10-26 외부 에셋 연결은 `AssetCatalog`(ScriptableObject) + 에디터 `AssetCatalogBuilder`로 정함. 이유: 빌드된 게임은 `Assets/` 경로를 못 읽고, `Resources`는 폴더 규칙을 강제하며, StreamingAssets 런타임 로딩(PNG/OGG 디코딩)은 코드가 많음. 카탈로그는 씬이 직접 참조하므로 빌드에 자동 포함되고, 파일이 없으면 코드 생성 폴백. 교체 절차: 파일을 넣고 `Tools/Build Project`.
- 2026-10-26 Dark Ambience Loop(추격·교전 배경음 예비)는 아직 ID를 주지 않음. 쓰기로 하면 `bgm_combat`을 추가하고 CC BY 3.0 크레딧을 넣는다.
- 2026-11-03 외부 에셋을 `Assets/_Project/`에 정리. 사용한 원본·라이선스와 재생성 스크립트는 `AssetSource/`에 두고(Unity 임포트 대상 밖), 쓰지 않는 원본 약 500MB는 삭제. 잘라내기·재채색은 Python·ffmpeg가 없어 PowerShell + .NET으로 처리.
- 2026-11-03 dyru 캐릭터에 총이 없어 `chars/held_*`를 겹쳐 그림(무기 교체가 쉬움). 시트 열은 페이지 설명 순서대로 걷기·총 들기·사격·근접으로 해석하고, 항상 총을 들고 있으므로 idle=총 들기, walk=총 들기+사격 2프레임, shoot=사격으로 씀. 근접 프레임은 `player_melee`로 추가.
- 2026-11-03 캐릭터 배정: 플레이어=회색(밝게), 경비병=주황 헬멧(어두운 붉은 갈색으로), 소총병=녹색 체크(채도·명도 낮춤). 문서에는 "4색 중 회색"이라 했지만 4색 시트에 회색이 없어 기본 시트(`shooter_up.png`)를 씀.
- 2026-11-03 `tile_wall.png`는 거의 검정 타일이고 1px 선을 넣지 않음. 타일에 넣으면 칸마다 격자가 보이므로, 바닥과 맞닿은 변에만 맵 렌더러가 선을 그림.
- 2026-11-03 Firearm Library에는 사격음만 있어 재장전은 RPG Audio `metalClick`, 빈 탄창은 Interface `click_002`로 대체. 소음권총은 원본 그대로 쓰고 코드에서 피치를 낮추지 않음.
- 2026-11-03 사격음 2개는 96kHz 24bit 녹음의 첫 발을 0.12초만 잘라 48kHz 16bit 모노 `.wav`로 저장(ogg 인코더가 없음). `amb_outdoor_night`는 받은 그대로 `.mp3`라서 확장자 규칙에 `.mp3` 추가.
- 2026-11-03 효과음 길이는 11.2 기준과 다른 것이 있음(문 0.92초, 경고음 0.5초 등). 파일 ID 맞춤을 우선하고 실제 길이는 ASSET_DIRECTION 3.2에 기록.
- 2026-11-03 Trees & Bushes는 시트가 불투명이라 바깥 잔디를 지워 작은 나무 2종만 씀. 큰 나무는 110px 안팎이라 64×64 규격에 안 맞아 제외. `foliage_*`는 전부 32×32.
- 2026-11-03 총구 화염은 16×16으로는 작아 4장을 24×20으로 통일, 이름은 변형 규칙대로 `muzzle_flash_1~4`. 왼쪽 끝이 총구.
- 2026-11-03 Bloodsplatter(고해상도)와 Neo둥근모(`.ttf` 없음)는 제외. 피격 피는 Reactorcore 9프레임을 `hit_blood_*`로 추가, 폰트 대체 순서에서 NeoDunggeunmo 삭제.
- 2026-11-03 외부 에셋이 없던 초상화·폭탄·탈출·유인탄·아이콘·자세 실루엣·패널·천장등·탄피를 코드로 그려 임시본으로 넣음(`AssetSource/drawn/`). 문서의 직접 제작 항목이지만 개발 전에 모두 갖추라는 요청에 따름. 픽셀을 지정한 코드 생성 에셋으로 보고 이미지 생성 AI는 쓰지 않음. 수업 규정이 이것도 생성 도구로 본다면 교체.
