# 요구사항 정의서

Oct 23, 2026 · @기완 · 개정 2판(목표 화면 반영)

## 1. 문서 개요

이 문서는 2D 탑뷰 전술 슈팅·잠입 게임(Unity)의 기능·비기능 요구사항을 하나의 기준으로 확정한 정의서다. 팀 의견이 갈렸던 15개 안건은 2.1장에서 한 안으로 통일했고, 팀이 고른 **목표 게임 화면 3장**(`docs/reference/`)에서 나온 결정은 2.3장에 정리했다. 3\~9장의 모든 요구사항은 이 결정을 따른다.

- **목적**: 구현·검수 범위를 하나로 고정해 팀원 간 해석 차이를 없앤다.
- **범위**: 싱글 플레이, 로컬 처리, Windows PC. 온라인 네트워크·게임 서버·계정·클라우드 저장은 제외한다. 상황 대사를 만드는 Qwen(`llama-server`)은 같은 PC에서만 쓴다.
- **근거 문서**: 상세 기획안(2026-10-13), 기말 프로젝트 기획 질문지 의견 취합(2026-10-22, 익재·최기완·김성범 응답 Q01–Q71), 목표 게임 화면 3장(2026-10-23), Qwen 상황 대사 기능정의서·DB 설계(`DB설계.md`, 2026-11-10).
- **통일 원칙**: ① 구현·검수 부담이 작은 안을 우선한다. ② 세 사람 중 둘 이상이 같은 방향이면 채택한다. ③ 채택되지 않은 의견은 S/C 등급 기능으로 살릴 수 있으면 살린다. ④ 체력·피해량·거리·시간 같은 튜닝 수치는 초기값으로 두고 담당자가 테스트하며 조정한다. ⑤ **화면에 보이는 요소는 목표 화면을 따르고, 게임 규칙은 2.1장 결정을 유지한다.** 목표 화면 때문에 규칙이 새로 생기면 2.3장에 따로 적는다.
- **결정 상태**: 2장은 팀 회의 전의 기본 확정안이다. 회의에서 바뀌면 해당 행만 고치고 3\~9장은 "결정 연계" 열의 번호로 찾아 함께 수정한다.

### 우선순위·단계 정의

| 등급 | 의미 | 적용 기준 |
| --- | --- | --- |
| M | 필수 | 기말 제출에 반드시 포함. 빠지면 미완성으로 본다 |
| S | 권장 | M이 끝난 뒤 일정 여유가 있을 때 구현 |
| C | 여유 | 모두 끝난 뒤 시간이 남을 때만 구현, 빠져도 무방 |
| X | 제외 | 이번 범위에 넣지 않음 |

단계는 **중간**(중간발표 시연에 필요) 또는 **기말**(기말 제출까지 구현)로 표기한다. 중간에 만든 기능은 기말에서도 유지한다.

| 15 | 성능 합격 기준 | 적 20명 동시 활성에서 60fps, AI 처리 2ms 이하(렌더링·물리 제외). 순간 지연은 최저 45fps(22ms)까지, 0.5초 넘게 지속 금지, 33ms 초과 프레임 0회. 측정은 적 20명 추격·교전 60초. 검수 PC는 팀원 PC 중 최저 사양. **2D 조명 켠 상태로 측정**(#21) | 두 팀원의 측정 조건이 같음 |

## 7. 제약 사항과 가정

### 제약 사항

- **엔진·환경**: Unity 6000.3.24f1, URP 2D, Windows PC, 싱글 플레이, 로컬 처리. AI 판단은 학습형 AI 없이 규칙 기반 FSM과 행동 트리만 쓴다. Qwen은 Unity 패키지 없이 로컬 `llama-server`에 HTTP 요청을 보내 대사 문장만 만든다.
- **에셋**: 허용된 무료 에셋 또는 직접 제작물만 쓰고 출처를 기록한다. 목표 화면은 **스타일 참고용**이며 그 게임의 그림·글꼴·대사를 가져오지 않는다. 생성 도구는 수업 규정 확인 후에만.
- **일정**: 중간발표 11/17, 기말 12/15. 11/14부터 기능 동결.
- **작업 시간**: 최기완 주 5\~10시간, 김성범 주 약 7시간, 익재 하루 2\~3시간.
- **제외 범위**: 인질 구출, 섬광탄, 잠금·열쇠·문 파괴, 측면 이동, 문 경로 우회 소리 전파, 얇은 벽·유리 관통, 마우스 감도·키 변경, 100×100 대형 맵, 온라인 네트워크, 대화 분기, 방탄 획득, 음성 녹음, Qwen이 AI 상태를 바꾸는 것.

### 가정

- 최기완 문서의 "익재"와 김성범 문서의 "이익제"는 같은 사람으로 보고 "익재"로 적었다.
- 팀장은 맡은 영역이 가장 넓은 최기완으로 가정했다.
- 익재의 "2\~3시간"은 하루 기준으로 보았다.
- 수업 요구사항 원문이 확인되지 않은 항목은 A\* 직접 구현, 생성 도구 허용 여부, 공식 일정이다. 원문이 우선이며 #5·#17·#19를 고친다.
- 모든 수치는 초기값이다. 단, 대소 관계(예: 소총 피해 > 권총 피해)는 유지한다. 이벤트 점수·반경은 맵 1에서 AI 담당(익재)이 조정한다.
- Qwen 모델 파일과 `llama-server` 실행은 각자 PC에서 준비하며 저장소에 넣지 않는다.
- 목표 화면 HUD의 하늘색 막대는 방탄, 전구 막대는 밝기, 스피커 막대는 소음으로 해석했다. 팀 해석이 다르면 #22~#24만 고친다.
