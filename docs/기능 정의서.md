# 기능 정의서

## 1. 문서 개요

이 문서는 게임이 제공하는 기능을 71개 기능으로 나누고, 각 기능의 동작 규칙·입력·출력·연동을 정의한다. 요구사항 정의서가 "무엇을 만들지"를 정한다면, 이 문서는 "각 기능이 어떻게 동작하는지"를 정한다.

- **대상 게임**: 단독 침투 → 탐색 → 목표 수행 → 탈출 흐름의 2D 탑뷰 전술 슈팅·잠입 게임(Unity 6000.3.24f1, URP 2D, Windows PC, 싱글 플레이).
- **목표 화면**: `docs/reference/ref_01_combat.png`(실내 교전), `ref_02_dialogue.png`(브리핑 대화), `ref_03_nightvision.png`(야간 투시). 화면 요소는 이 3장을 따른다.
- **기능 ID 규칙**: `FN-영역-번호`. 영역은 PLY(플레이어) · COM(전투) · VIS(시야·조명) · MAP(맵) · MIS(미션) · AI · BRK(상황 대사) · UI · SND(사운드) · DAT(데이터) · DBG(디버그).
- **확정 기준**: 요구사항 정의서 2장의 결정(#1\~#32)과 `DB설계.md`(월드 이벤트 22종·Qwen 상황 대사)를 그대로 따른다. 수치는 모두 **초기값**이며 담당자가 테스트 후 조정한다.
- **등급**: M 필수 / S 권장 / C 여유. 단계는 중간(중간발표) / 기말(기말 제출).

| Qwen | 같은 PC에서 따로 실행한 `llama-server`의 언어 모델. 상황 상태값을 받아 대사 한 줄과 감정을 돌려준다. AI 판단에는 쓰지 않는다 |

## 3. 플레이어 기능 상세

플레이어는 마우스 커서로 조준하며 단독으로 침투한다. 담당은 최기완이다.

| ID | 기능 | 동작 규칙 | 입력 → 출력·연동 | 등급·단계 |
| --- | --- | --- | --- | --- |
| FN-PLY-01 | 이동·조준·카메라 | 8방향 이동(대각선도 같은 속도). 캐릭터는 커서 방향을 바라보고 커서가 조준선이다. 카메라는 플레이어를 따라가며 커서 쪽으로 (커서 거리 × 0.3, 최대 3m) 앞당긴다. 조준 보조와 키 변경은 없다 | 이동 키·마우스 → 위치·시선 방향을 시야·소음·AI 감지에 전달 | M · 중간 |
| FN-PLY-02 | 이동 모드 | 걷기 기본, 달리기 ×1.5, 웅크리기 ×0.5. 걷기 소음 반경 6m(발소리 간격 0.6초), 달리기 9m(0.4초), 웅크리기 3m(0.8초). 배율은 적 게이지 상승 속도에도 곱해진다. 현재 모드는 HUD 자세 실루엣으로 표시 | 이동 모드 키 → 소음 이벤트, 감지 배율, HUD | M · 중간 |
| FN-PLY-03 | 무기 사용 | 권총(P-9)·소음권총(P-9 SD)·소총(AR-30) 3종, 좌클릭 사격. 권총류 단발, 소총 연사. 3종 모두 휴대, 권총으로 시작. 중간발표는 권총 1종 | 사격 입력 → 사격 요청(COM-01), 소음 이벤트, 전투 흔적(COM-04) | M · 중간(권총) / 기말(나머지) |
| FN-PLY-04 | 재장전·무기 전환 | 재장전 시간은 무기별(권총 1.5초). 탄창 부족분만큼 예비에서 채운다. 전환 지연 0.3초, 재장전 중 전환하면 취소되고 잔탄 유지 | 재장전·전환 키 → 탄약 상태를 HUD에 전달 | M · 중간 |
| FN-PLY-05 | 연막탄 투척 | 2개 보유. 던진 지점에서 반경 10m 소음이 3초간 발생하고 벽 감쇠 규칙을 따른다. 플레이어에게 영향 없음 | 투척 입력·조준 지점 → 소음 이벤트, 잔여 수량 HUD | S · 기말 |
| FN-PLY-06 | 체력·방탄·피격 반응 | 최대 체력 70, 방탄 20(최대 20, 회복 없음). 피해는 방탄이 먼저 1:1로 받고 남은 피해가 체력을 깎는다. 피격 시 0.1초 적색 깜빡임과 피격음(방탄이 받으면 `sfx_hit_armor`). 경직·밀림·둔화·무적 없음 | 피해 요청 → 체력 컴포넌트, HUD 체력·방탄 막대 | M · 중간 |
| FN-PLY-07 | 사망·재시작 | 체력 0 이하에서 사망을 한 번만 확정(isDead)하고 입력을 막은 뒤 미션 실패를 통보한다. 재시작하면 게임 씬을 다시 불러와 탐색 기억·적·소음·타이머·전투 흔적을 초기화한다 | 사망 이벤트 → 미션·AI·화면 | M · 중간 |

## 4. 전투·시야·맵 기능 상세

전투·시야·조명 계산은 최기완, 맵 데이터와 조명 배치는 김성범, 맵 로더는 최기완이 맡는다.

| ID | 기능 | 동작 규칙 | 입력 → 출력·연동 | 등급·단계 |
| --- | --- | --- | --- | --- |
| FN-COM-01 | 히트스캔 사격 | 발사 순간 조준 방향으로 사거리까지 선을 쏜다. 처음 닿는 적·벽·닫힌 문·창문·엄폐물에서 멈추며 관통하지 않는다. 궤적선 약 0.1초. 적이 쏜 탄은 다른 적을 무시한다 | 사격 요청 → 피해 요청, 무기 소음 이벤트 | M · 중간 |
| FN-COM-02 | 엄폐물·창문 차폐 | 완전 차폐형(`C`)은 시야·총알 차단, 반엄폐형(`c`)과 창문(`W`)은 총알만 차단하고 시야·빛은 투과. 모두 이동 불가, 파괴 불가 | 맵 데이터 → 시야·사격·AI 경로·밝기 계산 | M · 중간 |
| FN-COM-03 | 근접 제압 | F를 누르면 1.5m 안(벽에 막히지 않음)의 가장 가까운 적 등 뒤로 붙어 소음·비명 없이 즉시 제압. 방향·적 상태와 관계없다 | 근접 제압 입력 → 적 사망 이벤트(소음 없음), 처치 수 | M · 중간 |
| FN-COM-04 | 전투 흔적 | 사격 시 총구 화염(0.05초, 작은 점광원 포함)과 탄피 1개가 튄다. 피격 지점에 혈흔, 사망한 적은 시체 스프라이트로 바뀌어 남고 시체 옆 0.4m에 그 적의 무기 그림을 떨군다(줍기 없음). 혈흔·탄피는 오브젝트 풀 최대 512개(넘으면 오래된 것부터 재사용). 시체는 이동·시야·총알을 막지 않는다 | 사격·피해·사망 이벤트 → 화면 | M · 중간 |
| FN-VIS-01 | 시야 차폐 | 마우스 방향 기준 90° 부채꼴, 거리 12m. 벽·닫힌 문·높은 엄폐물 너머는 레이캐스트로 가린다 | 위치·시선·맵 → 보이는 영역 | M · 중간 |
| FN-VIS-02 | 탐색 기억 | 한 번 본 타일은 윤곽을 유지한 채 30\~40% 밝기 회색조로 남기고, 현재 시야 안은 조명 그대로, 미탐색 지역은 완전 암전. 시야 밖 적·아이템은 표시하지 않는다. 재시작·사망 시 지운다 | 보이는 영역 → 화면(조명 위에 덮는 오버레이) | M · 중간 |
| FN-VIS-03 | 시야 밖 문 상태 | 시야 밖 문은 마지막으로 본 상태를 유지하고, 다시 보면 실제 상태로 바꾼다. 문이 열리거나 닫히면 시야와 주변 밝기를 즉시 다시 계산한다 | 문 상태 이벤트 → 시야·밝기 갱신 | M · 중간 |

피해는 **전투가 계산하고 → 체력 컴포넌트가 방탄·체력 감소와 사망을 한 번만 확정하며 → 미션에 알린다**. 재시작 초기화는 최기완이 게임 씬을 다시 불러와 처리하고, 각 시스템은 OnDisable에서 구독을 해제한다.

### 시작 순서

1. 설정 JSON 검증(`events.json`·`qwen.json` 포함. Qwen 서버 연결은 첫 요청 때 확인)
2. 맵 로드(타일·바닥·조명)
3. 밝기 격자 계산
4. 플레이어·적·미션 생성
5. 이벤트 구독
6. 화면·사운드 준비
7. 브리핑 대화
8. 미션 시작

### 매 프레임 처리 순서

1. 입력
2. 플레이어 이동
3. 소음·월드 이벤트 발생
4. 감지(시각·청각·단서, 밝기 반영)·의심도 갱신
5. AI 상태 전환과 이동
6. 공격·피해
7. 사망 확정
8. 미션 판정
9. 화면 갱신(시야·조명·전투 흔적·대사·UI). Qwen 응답은 여기서 받아 검증·표시한다

감지와 길찾기는 여러 프레임에 나눠 처리해 AI 2ms 기준을 지킨다. 밝기 격자는 문·조명 변경 때만 부분 재계산한다. Qwen 요청은 비동기라 프레임을 기다리게 하지 않는다.

### 검수 기준

각 항목은 해당 담당이 확인하고 다른 담당이 한 번 더 확인한다.

- [ ] 이동 모드별 소음 반경이 걷기 6m·달리기 9m·웅크리기 3m이고 HUD 소음 미터와 자세 실루엣이 따라 바뀐다 (FN-PLY-02, FN-UI-01)
- [ ] 피해가 방탄 → 체력 순서로 줄고 HUD 두 막대가 맞게 바뀐다 (FN-PLY-06)
- [ ] 벽·닫힌 문·창문·엄폐물 뒤의 적은 맞지 않고, 적이 쏜 탄은 다른 적에게 피해를 주지 않는다 (FN-COM-01·02)
- [ ] 근접 제압은 뒤 120°·1.5m 안의 미발각 적에게만 된다 (FN-COM-03)
- [ ] 혈흔·탄피·시체가 남고 512개를 넘어도 메모리가 늘지 않는다 (FN-COM-04)
- [ ] 벽 뒤는 보이지 않고, 방문한 지형은 회색조로 남으며 재시작하면 지워진다 (FN-VIS-01\~03)
- [ ] 같은 위치에서 밝은 칸이 어두운 칸보다 빨리 발견된다(디버그 게이지로 확인). 문을 닫으면 그 너머 조명이 밝기에 더해지지 않는다 (FN-VIS-04, FN-AI-01)
- [ ] 같은 상황에서 적의 상태 전환이 FSM 표와 같다 (FN-AI-03·04)
- [ ] 소리는 벽·닫힌 문·창문 1개마다 절반, 열린 문은 그대로 (FN-AI-02)
- [ ] A\* 경로가 벽 모서리를 대각선으로 통과하지 않고 닫힌 문은 열고 지나간다 (FN-AI-08)
- [ ] 상태가 바뀌거나 이벤트를 인지할 때 대사가 뜨되 적 1명당 3초에 1회를 넘지 않는다 (FN-UI-07)
- [ ] Qwen 서버가 없거나 2초를 넘기면 기본 대사가 뜨고, Qwen 대사는 20자 이내 한국어 한 줄이며 플레이어 위치·무기를 말하지 않는다. 대사를 켜고 꺼도 상태 전이 로그가 같다 (FN-BRK-01\~03)
- [ ] 문·장전·깡통 소리, 탄피·혈흔·평소와 다른 문을 본 적이 조사하러 오고, 같은 사건을 직접 듣고 무전으로도 받아도 의심도가 한 번만 오른다 (FN-AI-10·13\~16)
- [ ] 문 앞 1.2m에서 `[SPACE] 열기`가 뜨고 Space로 열린다 (FN-UI-09, FN-MAP-02)
- [ ] 브리핑 대화 중 타이머·AI가 멈추고 선택지로 넘어간다 (FN-UI-10, FN-MIS-01)
- [ ] 같은 프레임 승패 4가지 경우가 표와 같다 (FN-MIS-05)
- [ ] 여러 적이 동시에 발견해도 발각 1회, 무전으로 안 경우 제외 (FN-MIS-06)
- [ ] 저장 손상 시 .bak 복원 또는 동의 후 초기화 (FN-DAT-02)
- [ ] 적 20명·조명 켠 상태에서 60fps·AI 2ms 이하, 같은 조건 3회 실행 로그가 같다 (NFR-01·02·05)
- [ ] 목표 화면 3장과 같은 구도의 스크린샷에서 HUD·대화창·조명 대비가 같다 (NFR-09)
